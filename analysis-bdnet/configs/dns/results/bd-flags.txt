================= libxdnstt -h
Usage:
  libs/libxdnstt.so [-doh URL|-dot ADDR|-udp ADDR] -pubkey-file PUBKEYFILE DOMAIN LOCALADDR

Examples:
  libs/libxdnstt.so -doh https://resolver.example/dns-query -pubkey-file server.pub t.example.com 127.0.0.1:7000
  libs/libxdnstt.so -dot resolver.example:853 -pubkey-file server.pub t.example.com 127.0.0.1:7000

  -doh string
    	URL of DoH resolver
  -dot string
    	address of DoT resolver
  -pubkey string
    	server public key (64 hex digits)
  -pubkey-file string
    	read server public key from file
  -report string
    	Reporting Name (default "App Name")
  -udp string
    	address of UDP DNS resolver
  -utls string
    	choose TLS fingerprint from weighted distribution (default "4*random,3*Firefox_120,1*Firefox_105,3*Chrome_120,1*Chrome_102,1*iOS_14,1*iOS_13")

Known TLS fingerprints for -utls are:
  none random Firefox Firefox_55 Firefox_56 Firefox_63 Firefox_65
  Firefox_99 Firefox_102 Firefox_105 Firefox_120 Chrome Chrome_58
  Chrome_62 Chrome_70 Chrome_72 Chrome_83 Chrome_87 Chrome_96 Chrome_100
  Chrome_102 Chrome_120 iOS iOS_11_1 iOS_12_1 iOS_13 iOS_14
